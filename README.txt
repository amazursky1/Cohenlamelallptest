Cohen & Lamela — iPhone-friendly GitHub Pages package

This version is intentionally FLAT:
- All .html files are in the repository root.
- All .webp image files are also in the repository root.
- There is NO images folder.

Why:
GitHub's mobile/iPhone upload flow often does not allow uploading an entire folder.
This lets you select all HTML and WebP files together and upload them at once.

Upload all files in this folder directly into the root of your GitHub repository.
